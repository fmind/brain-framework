# Learn a reusable procedure

Use when several completed actions appear to teach the same lesson. Inspect a small set of outcomes within the relevant project, not all transcripts: their expectations, actual results, circumstances and source refs.

Propose a concept or an update to the existing owning skill: when it applies, the steps or decision rule, prerequisites, failure conditions, examples and counterexamples. Label a lesson from one event provisional; repeated summaries of one event, or a claim an agent merely repeated, are not independent confirmation.

Before promoting it, try the procedure on one relevant case not used to derive it, with a synthetic fixture or a user-authorized task, and record the result. Without such a case, keep `status: draft` and name the missing check; never mark `verified` without a real check and verifier. Failed cases narrow the procedure and stay in its provenance.

Extend the owning concept or skill before creating another, link to the original actions instead of copying their private inputs and never rewrite collected records to support a lesson.
