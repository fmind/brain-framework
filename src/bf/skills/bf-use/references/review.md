# Review knowledge periodically

Use for a requested weekly, monthly or project review. Take the brain, projects and period from the request and reuse established scope and authorization; a review needs no action, new skill or schedule.

1. Read `bf read projects`, `bf read concepts` and `bf read actions` for notes needing review, `bf read tasks` for open work and a period such as `bf read 2026-09-21..2026-09-27` for activity, following `next_offset` when the review needs every page. Prioritize the selected projects, blockers and decisions whose review date or event has arrived, and state what remains unreviewed.
1. Read each selected project and the refs needed to assess it. A `review: true` flag is a reason to inspect, never proof that a note is wrong, and clearing it is no verification: check `review_reasons` and read the refs `newer` lists. A project falls due 14 days after its last edit unless it sets `stale_after`, any other note only by `stale_after`, which survives the copies and checkouts that reset file times. Missing or incomplete evidence leaves a conclusion unknown.
1. Compare each consequential decision's recorded expectation with the observed outcome: met, missed or unknown. Keep the original prediction and its evidence; never rewrite hindsight as foresight, and never count an untested outcome as a failed prediction. Use the [evidence guide](evidence.md) when a source changed or a belief needs revision.
1. Revisit open unknowns and conditional intentions in the owning project, following the [decision conventions](decisions.md). A ready intention proposes a next step; it never authorizes external work.
1. When updates are authorized, revise each owning note's current state and next actions, keeping material contradictions and decision evidence, and set `stale_after` only for a real deadline; otherwise present the proposed edits. Use [consolidation](consolidate.md) only when outcomes support a reusable lesson.
1. Run `bf validate`, and `bf eval` after adding a case for an answer that must stay findable. Report changed conclusions, unknowns, the next useful action and coverage limits with their refs, keeping conclusions in their owning notes rather than review summaries.
