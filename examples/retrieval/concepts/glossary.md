# Glossary

Short definitions shared by the fictional teams.

## Backlog

Work accepted but not yet started.

## Baseline

A measurement kept for later comparison.

## Cache

A disposable copy that speeds up repeated queries.

## Checklist

An ordered list of steps to confirm.

## Credits

The unit used to plan launch budgets.

## Dashboard

A page that summarizes current measurements.

## Field report

A short account written by an office team.

## Fixture

Fictional input data used by tests.

## Handoff

A transfer of ownership to another person.

## Import

Loading data from an external file.

## Latency

The delay between a request and its reply.

## Onboarding

Preparing a new partner team to work with us.

## Owner

The person accountable for a project.

## Partner

An external team that shares work with us.

## Profile

A record of where a program spends its time.

## Spreadsheet

A table of rows and columns kept in one file.

## Sync

Keeping two copies of the same data consistent.
