# fkf-contribute

Read AGENTS.md first. Keep one package and command, normalized JSON captures, flat projects/tasks/wiki Markdown, source-organized captures and disposable SQLite/structure indexes. Provider projection, schedules and harness installation belong to base maintenance. Keep only the current data format; do not add migration or compatibility code.

Test observable behavior and failures with synthetic data and fake providers. Preserve offline reads, path confinement, bounded output, atomic writes, process cancellation, explicit collection and retained original evidence. Do not run live providers without task authorization or weaken a check.

Run focused tests and `mise run all`. Update schema, README, docs, the user skills under `skills/` and the adapter catalog under `adapters/` with public behavior; an adapter change needs a fake-provider test and a README table entry. Preserve unrelated changes; commits, publication and provider execution follow the user's explicit scope.
