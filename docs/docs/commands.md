# Command reference

Data goes to stdout as compact JSON; diagnostics go to stderr. Exit 0 means success, 1 a failure or failed check, 2 invalid input and 130 cancellation. `fkf COMMAND --help` lists every option.

| Command                                                                                  | Contract                                                                                                                                                                          |
| ---------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `init PATH [--name NAME]`                                                                | Create a base in a new or empty directory and register it with collection trust.                                                                                                  |
| `register [PATH] [--collect]`                                                            | Add an existing base to `~/.config/fkf/config.yaml`; `--collect` lets this machine run its collectors.                                                                            |
| `search [QUERY] [--since] [--until] [--source] [--type] [--status] [--limit] [--recent]` | Search words or an identity, or list by time window or filter. See [search](search.md).                                                                                           |
| `read REF`                                                                               | Read a note, `note#section`, `source:id` record or explicit identity.                                                                                                             |
| `update [--dry-run]`                                                                     | Run due sources of every trusted base, then refresh their caches. Dry-run runs nothing.                                                                                           |
| `collect SOURCE [--since] [--until] [--dry-run]`                                         | Run one source now; the window defaults to its lookback. Dry-run shows three samples and writes nothing.                                                                          |
| `status [--check]`                                                                       | Per base: cache state, notes, records and each source's freshness, last error and log. `--check` exits 1 when a trusted scheduled source is stale, failed, or a file was skipped. |
| `validate`                                                                               | Check notes, OKF wiki structure, links, cited records and record partitions; exit 1 on problems.                                                                                  |
| `eval [--path queries.yaml]`                                                             | Run retrieval cases; exit 1 when one fails.                                                                                                                                       |
| `build`                                                                                  | Rebuild the search cache from scratch. Search keeps it current anyway.                                                                                                            |
| `mcp`                                                                                    | Serve `search` and `read` over MCP stdio.                                                                                                                                         |
| `schema`                                                                                 | Print the JSON Schema of `fkf.yaml`.                                                                                                                                              |

Every base command accepts `--base NAME|PATH`. Without it, commands use `FKF_BASE`, then the base containing the working directory, then every registered base. Commands that act on a single base (`collect`, `validate`, `eval`, `build`) ask for `--base` when several are registered.
